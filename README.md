# Agenda API — Laravel

> 🚧 **Projeto em construção**

API de agenda desenvolvida em Laravel como projeto de portfólio e prática de backend.

A proposta é construir uma base simples e organizada para operações de agendamento, explorando autenticação, regras de negócio, persistência de dados e endpoints REST.

## Objetivos do projeto

- estruturar uma API REST em Laravel;
- praticar organização de regras de negócio no backend;
- trabalhar com validação, autenticação e persistência;
- evoluir a cobertura de testes;
- documentar decisões e aprendizados ao longo do desenvolvimento.

## Stack

- PHP
- Laravel
- SQL / banco relacional
- APIs REST
- Git / GitHub

## Status atual

O projeto está **em desenvolvimento** e ainda não representa uma versão final de portfólio.

A documentação será expandida conforme novas funcionalidades forem concluídas e validadas.
